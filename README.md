# Homework 1

Сервис модерации объявлений на FastAPI, Python 3.12 и uv

## Запуск

```bash
uv sync --locked
uv run fastapi dev
```

После активации `.venv` можно запускать командой `fastapi dev`

Документация API: http://127.0.0.1:8000/docs

## API

`GET /` возвращает `{"message": "Hello World"}`

Пример JSON для `POST /predict`

```json
{
  "seller_id": 42,
  "is_verified_seller": false,
  "item_id": 101,
  "name": "Велосипед",
  "description": "Городской велосипед в хорошем состоянии",
  "category": 3,
  "images_qty": 0
}
```

Все поля обязательны. Идентификаторы и категория принимают положительные целые числа,
количество изображений должно быть целым числом от нуля. Название и описание не могут
быть пустыми после удаления пробелов по краям. Типы проверяются строго,
лишние поля и `null` не принимаются

В ответе возвращается `true`, если есть нарушения, иначе `false`.
Подтверждённый продавец всегда проходит проверку. Неподтверждённому
нужно хотя бы одно изображение. Для примера выше вернётся `true`

При успешной проверке возвращается статус `200`, при некорректном запросе `400`,
при внутренней ошибке `500`. Тело ошибки содержит поля `code`, `message`, `details`

Обработчики находятся в `src/moderation/api`, бизнес-логика в `services`,
правила проверки в `repositories`, модели в `domain`
